# Hospital Management System (C Project)

A university-level C project designed to digitize hospital operations.  
This system integrates multiple user roles — **Director, Administrator, Doctor, Nurse, and Patient** — each with specific functionalities that collectively improve workflow efficiency.

---

## 🚀 Features

### 👨‍💼 Director
- Secure login
- Add/View Administrators
- Generate staff reports
- View appointment summaries

### 🛠️ Administrator
- Register Patients, Doctors, Nurses
- View/Search patient records
- Manage inventory (view/search)

### 👨‍⚕️ Doctor
- View assigned appointments
- Add medical records
- View patient history

### 👩‍⚕️ Nurse
- View doctor schedules
- Add/View/Search inventory
- Generate staff & inventory reports

### 🧑 Patient
- Book, reschedule, cancel appointments
- View billing details
- Pay via card or online banking
